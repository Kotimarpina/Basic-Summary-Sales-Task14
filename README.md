# Task 14: Basic Sales Summary — Sample Superstore

## Project Overview

This project focuses on creating a basic sales summary using Microsoft Excel and the Sample Superstore dataset. The goal is to calculate key business metrics and organize them into a simple summary sheet that makes sales performance easier to understand.

## Objective

- Calculate total sales.
- Calculate average sales.
- Determine the transaction count.
- Present the results using three key performance indicators (KPIs).
- Verify calculated totals using formulas and manual checks.

## Dataset

**Dataset Name:** Sample Superstore

The dataset typically contains sales-related information such as Order ID, Order Date, Customer ID, Product Name, Sales, Quantity, Discount, and Profit. The exact columns depend on the version used.

## Tools Used

- Microsoft Excel
- Excel formulas
- Tables and cell formatting
- Optional charts for visual presentation

## KPIs

| KPI | Description |
|---|---|
| Total Sales | Sum of all sales values |
| Average Sales | Average sales value per data row |
| Transaction Count | Number of transactions or sales records, depending on the counting method |

## Methodology

1. Import the Sample Superstore dataset into Excel.
2. Inspect the column names and check for missing or invalid values.
3. Convert the dataset into an Excel Table.
4. Use formulas to calculate total sales, average sales, and transaction count.
5. Create a dedicated summary sheet.
6. Format the KPIs clearly and add optional visualizations.
7. Verify the results against the source data.

## Deliverables

- **Summary Sheet:** Displays the three calculated KPIs.
- **Three KPI Indicators:** Total Sales, Average Sales, and Transaction Count.
- **Optional Chart:** A simple sales chart to support visual interpretation.
- **Validated Results:** Formula-based calculations checked for accuracy.

## Key Learnings

- Using Excel formulas for basic business analysis.
- Understanding the difference between totals, averages, and counts.
- Creating a readable KPI summary.
- Validating calculations before presenting results.
- Communicating business information clearly.

## Conclusion

This task demonstrates how Excel can turn raw sales records into a concise business summary. The resulting KPIs provide a useful starting point for understanding sales activity and support further analysis.
